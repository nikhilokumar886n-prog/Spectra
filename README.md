# spectra

A color-memory game that challenges you to remember and recreate colors as accurately as possible.

## Play the Game

[Play Spectra](https://spectra-ecru.vercel.app/)

## About

Spectra is a five-round color memory game. In each round, a randomly generated color is shown for a few seconds. The player then tries to recreate the same color using Hue, Saturation, and Brightness sliders.

After each round, the recreated color is compared with the original color and the player receives a score based on how accurately they matched it.

At the end of all five rounds, the scores are combined into a final score out of 50.

## Features

- Randomly generated colors
- Five-round memory challenge
- Hue, Saturation, and Brightness controls
- Live color preview
- Color similarity scoring
- Individual round scores
- Final score out of 50
- Performance-based feedback
- WhatsApp score sharing
